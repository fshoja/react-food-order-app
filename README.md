# 🍔 Food Order App

## معرفی پروژه

یک اپلیکیشن سفارش غذا ساخته شده با React که امکان مشاهده غذاها، جستجو، فیلتر دسته‌بندی و مدیریت سبد خرید را فراهم می‌کند.

## Features

- نمایش لیست غذاها
- جستجوی غذا
- فیلتر غذاها بر اساس دسته‌بندی
- اضافه کردن غذا به سبد خرید
- حذف غذا از سبد خرید
- افزایش و کاهش تعداد محصولات
- محاسبه قیمت کل سبد خرید
- طراحی Responsive

## Technologies

- React
- JavaScript (ES6+)
- React Router
- Context API
- CSS3
- Vite
