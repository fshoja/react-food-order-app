# 🍔 Food Order App

A modern and responsive Food Ordering application built with React. Users can browse food items, search by name, filter by category, and manage their shopping cart.

## 🚀 Live Demo

https://react-food-order-app-mu.vercel.app/

## ✨ Features

- Browse food menu
- Search food items
- Filter foods by category
- Add items to cart
- Remove items from cart
- Increase and decrease item quantity
- Calculate total cart price
- Responsive design
- React Router navigation
- Context API state management

## 🛠 Technologies

- React
- JavaScript (ES6+)
- React Router DOM
- Context API
- CSS3
- Vite

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/fshoja/react-food-order-app.git
```

Go to the project folder:

```bash
cd react-food-order-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
