# 🍔 Food Order App

A modern and responsive Food Ordering application built with React and Vite. Users can browse the menu, search and filter foods, add items to the cart, manage quantities, and view the total price.

## 🚀 Features

- Browse food menu
- Search foods by name
- Filter foods by category
- Add products to the shopping cart
- Remove products from the cart
- Increase and decrease item quantity
- Calculate total cart price
- Responsive user interface
- Client-side routing with React Router
- Global state management using Context API

## 🛠 Technologies

- React
- JavaScript (ES6+)
- Vite
- React Router
- Context API
- CSS3

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/fshoja/react-food-order-app.git
```

Go to the project folder:

```bash
cd react-food-order-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
